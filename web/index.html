从一段指令开始

生成一段接入指令，发给你任意一台机器上的 Agent，它会自己完成注册并开始上报心跳。

  1. 生成指令点击右上角「接入新 Agent」，令牌 24 小时内有效
  2. 发给 Agent原样粘贴到它的对话窗口，等待它汇报执行结果
  3. 回到这里状态灯变绿，即接入完成

设置

基本设置

平台地址（Base URL）

Agent 的注册与心跳请求都发往这个地址，新生成的接入指令立即生效。已接入 Agent 的心跳地址在首次注册时已写入其本地配置，改地址后需要重新接入。

轮询间隔（秒）

Agent 心跳与任务拉取的频率，全局生效，10-3600 秒。改动随心跳下发，各实例一分钟内自动重装本机定时任务，无需重新接入。cron 环境的机器只支持分钟粒度，会自动向下取整。
